PORTFOLIO DASHBOARD - STARTER

Files:
- app.py: Streamlit dashboard
- portfolio.csv: editable sample holdings
- requirements.txt: dependencies

Run locally:
1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Run: pip install -r requirements.txt
4. Run: streamlit run app.py
5. Edit portfolio.csv with your holdings and prices.

Important: sample prices are illustrative, not live market data. This starter dashboard does not connect to a broker or market-data API.
